Principios de Ingeniería

Reglas de Arquitectura No Negociables

Lógicas garantizadas a nivel de código para asegurar rigor SOX, reproducibilidad y confiabilidad en la cadena de suministro.

1. Cálculo Aislado en Engine

Toda fórmula de negocio reside exclusivamente en src/engine/ como funciones puras y determinísticas. Ningún componente React realiza cálculos directos.

2. Interfaz DataProvider

Desacoplamiento total entre la UI y la fuente de datos. Se conmuta de forma transparente entre datos simulados (MockProvider) y Google Sheets Apps Script API.

3. Bitácora de Auditoría Inmutable

Toda acción de modificación genera una fila en app_auditoria especificando timestamp, usuario, entidad, valor anterior, nuevo valor, motivo y versión de regla.

4. Solo Bajas Lógicas

Está estrictamente prohibido eliminar físicamente registros. La desactivación o retiro de SKUs, usuarios o políticas se realiza cambiando el atributo estado.

5. Control Versión de Reglas

Cualquier modificación en las fórmulas de cálculo obliga al incremento de RULES_VERSION en src/engine/version.ts para trazabilidad histórica.

6. Recomendador, No Automatizador

La aplicación NUNCA emite una Orden de Compra (OC) de forma autónoma. Sugiere parámetros y registra formalmente la aprobación o ajuste del Planner.

Caso Emblemático: Carnauba T1 (`INS-001`)

Insumo orgánico importado desde Brasil/Asia para el recubrimiento de frutas de exportación.

SKU Crítico Clasificación A

Cera de Carnauba T1 Importada

Este insumo sufre de tiempos de tránsito marítimo prolongados (Lead Time de 60 días) y un pico drástico de demanda entre los meses de Agosto y Noviembre debido a la campaña de palta y mango de exportación.

  • Stock de Seguridad (SS): Calculado con variabilidad de demanda y servicio del 95%.
  • Punto de Reorden (ROP): Alerta activada cuando la Posición ≤ ROP.
  • Evaluación Estacional: La cobertura no se calcula con un promedio anual plano.
Fórmula de Cobertura Estacional (Engine):
\[ Cobertura (días) = \text{Días hasta agotar Stock vs } D_{mes1}, D_{mes2}, ... \]
Fórmula de OTIF (On-Time In-Full):
\[ OTIF = (A\ Tiempo \le 0\ días) \ \land \ (Cantidad\ Recibida == Cantidad\ Solicitada) \]
